## Installation & Setup

1. **Clone the repository**
   ```bash
   git clone git@github.com:Rushwind13/boxbox.git
   cd boxbox

2. **Python Virtual Environment**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip3 install --upgrade pip
    pip3 install -r requirements.txt

To run tests:
`pytest tests/`
